# Levantamento de requisitos

Esta pasta reúne dúvidas e reuniões usadas para definir os requisitos. Qualquer contribuinte pode adicionar uma pergunta pertinente quando ela surgir.

## Arquivos

- [Perguntas](./perguntas.md): índice mestre e estado atual de cada pergunta.
- [Reunião 1](./reuniao-01.md): perguntas previstas para a primeira reunião e espaço para registrar as respostas.

## Regras

1. Cada pergunta recebe um ID universal no formato `QNNN`.
2. O ID é permanente e deve ser repetido em qualquer reunião que contenha a pergunta. Exclusões ou mudanças de ordem não provocam renumeração.
3. O índice mestre apresenta a pergunta primeiro, seguida por etiquetas de status e reunião. Ele não contém respostas.
4. Os status permitidos são:
   - `ABERTA`: nenhuma resposta foi obtida.
   - `PARCIAL`: há informação, mas ainda falta uma decisão ou complemento.
   - `RESPONDIDA`: a resposta é suficiente para orientar o requisito.
5. A reunião deve aparecer como um link curto, como [`R1`](./reuniao-01.md). Se a pergunta ainda não estiver em uma reunião, o link é omitido.
6. As respostas do cliente são registradas somente nos arquivos de reunião.
